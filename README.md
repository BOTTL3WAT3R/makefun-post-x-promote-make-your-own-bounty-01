My entry for make.fun's bounty promoting its make-your-own-bounty post on X. The entry itself is one post on X that links to make.fun's post, carries a photo of its own, and names make.fun and my play code in its text. This repository names that post in POST.json, and main.ts copies POST.json to the output directory for the grader, after checking the address really is one X post.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
